# 한글 소리 실험실 · 발음 학습 웹앱

자음과 모음을 결합하고 소리를 들으며 한글을 연습하는 정적 웹앱입니다. 1~7단계의 글자 조합, 단어 소개와 그림 연습, 받침 학습이 들어 있습니다. 학습 안내는 한국어로 표시되며, 일부 설명과 단어에 마우스를 올리거나 터치하면 번체 중국어 번역을 볼 수 있습니다.

## 실행

이 폴더의 `index.html`을 브라우저에서 열면 됩니다. 이미지가 보이지 않는 브라우저에서는 아래 명령으로 로컬 서버를 실행한 뒤 `http://localhost:8000`에 접속하세요.

```sh
python3 -m http.server 8000
```

발음은 브라우저의 음성 합성 기능을 사용합니다. 한국어 음성이 기기에 설치되어 있지 않거나 브라우저에서 지원하지 않으면 소리가 다르게 들리거나 재생되지 않을 수 있습니다.

## GitHub에 올리기

이 폴더 전체를 GitHub 저장소의 최상위에 올리세요. `index.html`과 `stage2-images`부터 `stage7-images`까지의 이미지 폴더를 함께 올려야 합니다.

GitHub Pages로 공개하려면 저장소의 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**, `main`, `/ (root)`를 선택하세요. 공개 주소는 GitHub가 표시해 줍니다. 이미지 경로는 상대 경로로 작성되어 있어 저장소 이름과 관계없이 작동합니다.

## 구성

- `index.html`: 화면, 학습 데이터, 상호작용, 음성 재생 코드
- `word-illustrations.png`, `stage2-images`~`stage7-images`: 학습용 그림

이 웹앱에는 빌드 과정이나 외부 패키지 설치가 필요하지 않습니다.
